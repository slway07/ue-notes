Projectile · Rotating · InterpTo · Floating

발사체의 중력·바운스·호밍·정지, 충돌 없이 회전하는 Rotating, 제어점을 잇는 InterpTo, 입력으로 뜨는 Floating, 그리고 직접 만드는 커스텀 무브먼트.

개요 캐릭터 물리 네트워크 Root Motion 그 외

1. ProjectileMovement — 발사체

UProjectileMovementComponent 는 Velocity 를 적분해 UpdatedComponent 를 옮긴다. 캐릭터처럼 입력·마찰·계단을 다루지 않고, 속도·중력·충돌·바운스 만 다룬다.

한 틱의 순서는 이렇다.

  1. 보간 — TickInterpolation. 시뮬레이션이 끝난 뒤에도 남은 보간을 마저 한다.
  2. 루프 — ShouldUseSubStepping() 이면 GetSimulationTimeStep 으로 시간을 쪼갠다. 중력이 있거나 호밍 중이면 자동으로 켜진다.
  3. 이동량 — ComputeMoveDelta 가 velocity Verlet(p = p0 + v0*t + 1/2*a*t^2)로 delta를 만든다.
  4. 회전 — bRotationFollowsVelocity 면 속도 방향으로 돌린다. bRotationRemainsVertical 이면 Yaw만 남긴다.
  5. 스윕 — 바운스가 있으면 SafeMoveUpdatedComponent(관통 보정 포함), 없으면 MoveUpdatedComponent 에 MOVECOMP_NeverIgnoreBlockingOverlaps 를 걸어 첫 충돌을 놓치지 않는다.
  6. 충돌 처리 — HandleBlockingHit → HandleImpact. 바운스면 HandleDeflection, 아니면 StopSimulating.
  7. 속도 갱신 — 충돌이 없었으면 ComputeVelocity 로 중력·호밍을 더한다.

서브스텝 기본값은 캐릭터와 다르다. MaxSimulationTimeStep = 0.05, MaxSimulationIterations = 4, 그리고 바운스 직후 한 번 더 돌리는 BounceAdditionalIterations = 1 이다.

2. Projectile — 값과 충돌

  • InitialSpeed 기본 0 — 0보다 크면 Velocity 의 크기를 덮어쓰고, Velocity 는 방향으로만 쓰인다
  • MaxSpeed 기본 0 — 0이면 무제한. LimitVelocity 가 클램프
  • ProjectileGravityScale 기본 1 — 0이면 직선. 중력이 있으면 서브스텝 자동
  • bShouldBounce 기본 false — false면 첫 충돌에서 정지
  • Bounciness · Friction 0.6 · 0.2 — 튕김 계수와 마찰
  • BounceVelocityStopSimulatingThreshold 기본 5 — 이 속도 아래로 떨어지면 정지
  • bRotationFollowsVelocity 기본 false — 속도 방향 회전
  • bInitialVelocityInLocalSpace 기본 true — 초기 속도를 액터 로컬 기준으로 해석
  • bSweepCollision 기본 true — 스윕 사용. 끄면 순간이동
  • bInterpMovement · bInterpRotation 기본 false — 시뮬레이티드 프록시 보간. InterpLocationTime 0.1 · InterpRotationTime 0.05

정지는 StopSimulating 이다. 속도를 0으로 만들고, UpdatedComponent 를 null로 하고, OnProjectileStop 을 브로드캐스트한다. 그래서 정지한 뒤에는 그 컴포넌트가 더 이상 무브먼트의 대상이 아니다.

바운스는 HandleDeflection 이 법선을 기준으로 속도를 반사하고, Bounciness·Friction 을 적용한다. 같은 자리에서 여러 번 튕기면 bIsSliding 으로 미끄러지고, 코너에서는 두 법선의 외적으로 방향을 만든다. OnProjectileBounce 가 매 바운스마다 나간다.

호밍은 HomingTargetComponent·HomingAccelerationMagnitude 로 목표를 향해 가속한다. 호밍 중이면 ShouldUseSubStepping 이 true가 되고, MaxSpeed 가 전체 속도를 제한한다.

3. RotatingMovement — 충돌 없이 회전

URotatingMovementComponent 는 RotationRate 만큼 UpdatedComponent 를 회전시킨다. 기본은 Yaw 180도/초, 로컬 공간 회전이다.

const bool bEnableCollision = false;
MoveUpdatedComponent(DeltaLocation, NewRotation, bEnableCollision);

MoveUpdatedComponent 에 충돌을 끈 채 넘긴다. 그래서 회전하는 문·선풍기 날개·회전 플랫폼이 벽이나 캐릭터를 밀어내지 않는다. 충돌이 필요하면 Rotating으로 해결하지 말고, 물리 액터나 별도 처리를 써야 한다.

PivotTranslation 은 회전 중심을 옮긴다. 예를 들어 X=+100이면 그만큼 떨어진 점을 축으로 돌아간다. bRotationInLocalSpace 는 부모 회전을 기준으로 돌지, 월드 기준으로 돌지를 정한다.

4. InterpToMovement — 제어점 사이

UInterpToMovementComponent 는 ControlPoints 사이를 Duration 동안 보간한다. 문이 열리는 경로, 엘리베이터, 왕복 플랫폼처럼 정해진 경로가 있을 때 쓴다.

값동작
ControlPoints경로 점. 상대/월드, 액터 기준점을 섞을 수 있다
Duration한 구간을 이동하는 시간
BehaviourTypeOneShot · OneShot_Reverse · Loop_Reset · PingPong
bSweeptrue면 이동 중 충돌 스윕. 기본 true
bPauseOnImpact충돌하면 멈출지, 끝점에 도달한 것처럼 행동할지
SpeedMultiplier전체 재생 속도
OnInterpToStop정지 이벤트

bSweep 이 true면 SafeMoveUpdatedComponent 로 이동하고, 충돌 시 bPauseOnImpact 에 따라 멈추거나 방향을 바꾼다. StopMovementImmediately 는 UpdatedComponent 를 null로 만들지 않는다. Projectile의 StopSimulating 과 다른 점이다.

5. FloatingPawnMovement — 입력으로 뜨는 Pawn

UFloatingPawnMovement 는 UPawnMovementComponent 계열이다. 중력·바닥 없이 입력으로 가속·감속하고, SafeMoveUpdatedComponent 로 스윕한다.

값기본동작
MaxSpeed1200최고 속도
Acceleration4000입력이 있을 때 가속
Deceleration8000입력이 없을 때 감속
TurningBoost8방향 전환 부스트

컨트롤러 입력이 있으면 ApplyControlInputToVelocity 로 속도를 만들고, Delta = Velocity * DeltaTime 을 스윕한다. 충돌하면 HandleImpact 후 남은 시간을 다시 처리한다. LimitWorldBounds 로 월드 경계를 넘지 않게 한다.

6. 커스텀 무브먼트 — 무엇을 상속할까

  • UMovementComponent — 가장 가볍다. UpdatedComponent 를 직접 옮기고 싶을 때. Pawn 이 아니어도 된다.
  • UPawnMovementComponent — PawnOwner 와 입력(AddInputVector)이 필요할 때. UFloatingPawnMovement 가 좋은 예.
  • UCharacterMovementComponent — 캐릭터. 걷기·낙하·계단·네트워크 예측을 다시 만들지 말고 이것을 쓴다.

오버라이드 지점은 이렇다.

  • TickComponent — Super 호출 후 delta를 만들고 SafeMoveUpdatedComponent.
  • MoveUpdatedComponentImpl — 이동 방식을 바꾸고 싶을 때.
  • GetMaxSpeed — 길찾기·AI가 참조하는 최고 속도.
  • RequestDirectMove·RequestPathMove — UPathFollowingComponent 가 경로를 넘길 때.
  • StopActiveMovement — 정지 요청.

무브먼트 컴포넌트 자체는 자동으로 복제되지 않는다. Velocity·상태를 액터의 bReplicateMovement 로 보내거나, 직접 RPC/리플리케이션을 붙여야 한다. CharacterMovement처럼 예측·보정을 공짜로 얻는 것은 아니다.
